# HISTORY QUEST

Қазақстан тарихына арналған серверлік оқу платформасының іске қосылатын бастапқы нұсқасы.

## Жергілікті іске қосу

Node.js 22.5+ қажет. Ешқандай npm пакеті қажет емес.

macOS/Linux:

```bash
cd history-quest
CURATOR_PIN='ӨЗІҢІЗДІҢ_КҮРДЕЛІ_ҚҰПИЯСӨЗІҢІЗ' node server.js
```

Windows PowerShell:

```powershell
$env:CURATOR_PIN='ӨЗІҢІЗДІҢ_ҚҰПИЯСӨЗІҢІЗ'
node server.js
```

Сайт: http://localhost:3000

## Құрам

- 57 аты-жөн (берілген тізімде 56 емес, 57 адам бар).
- 1-күн: 40 тест, 5 хронология, 5 контекст — жалпы 50 бастапқы тапсырма.
- 2–6-күн: сұрақтар енгізілмеген. Тексерілмеген тарихи деректерді ойдан қоспау үшін бос қалдырылған.
- Оқушы алғаш кіргенде аты-жөнін таңдап, 4–8 санды PIN орнатады.
- Нәтижелер `data/results.sqlite` ішінде сақталады; сервер қайта қосылса да жоғалмайды.
- Қателерді қайта жаттығу, кураторлық есеп, CSV экспорт, JSON сұрақ импорттау бар.
- Контекстің автоматты бағасы — үш кілт тіркестің кездесуі бойынша алдын ала баға; семантикалық тексеру немесе қолмен бағалау емес.

## Интернетке орналастыру

Серверді Node.js іске қосатын хостингке жариялаңыз. Тұрақты сақтау дискісін `data/` қалтасына бекітіңіз, HTTPS қолданыңыз және `CURATOR_PIN` айнымалысын орнатыңыз. Дерекқор файлын көпшілікке ашпаңыз. Оқушының PIN-ін басқа біреу бірінші болып тіркеп кетпеуі үшін оқушыларға жеке PIN-дерді алдын ала беру және кураторлық PIN қалпына келтіру функциясы өндірістік қолдануға дейін қосылуы тиіс. Аты-жөнді таңдау ғана жеке тұлғаны растамайды.

## Сұрақтарды қосу

Куратор панелінен JSON импорттаңыз. Үлгі: `sample-import.json`. Әр күнге дәл 40 `mc`, 5 `order`, 5 `context` тапсырмасы қажет. Импорттау қазір тек жалпы 50 лимитін тексереді; форматтық пропорцияны куратор өзі тексеруі тиіс. Қате жауаптар мен бағаларды сақтау үшін бұрынғы `id` мәндерін өзгертпеңіз.

## Шектеулер

Бұл дайын сайттың **жұмыс істейтін жергілікті нұсқасы**, бірақ толық 300 сұрақтық контент және жарияланған көпқұрылғылы интернет қызметі емес. Қолданушыларды басқару, PIN қалпына келтіру, қолмен контекст бағалау, өндірістік қауіпсіздік аудиті және 250 қосымша сұрақ енгізу қажет.

## 300 тапсырмалық жаңарту (2026-11-11)

`data/questions.json` ішінде енді 6 күн × (40 тест + 5 хронология + 5 контекст) = **300 тапсырма** бар. Тесттердің жауап нұсқалары араластырылған, ал хронология оқиғаларының атауында жыл көрсетілмейді.

**Мазмұндық шектеу:** бұл 300 *жеке тапсырма*, бірақ 70 тексерілген факт картасының негізінде жасалғандықтан кей тарихи білім бірнеше күнде қайталанады. Бұл 300 тәуелсіз тарихи факт не 300 бір-біріне ұқсамайтын мазмұн дегенді білдірмейді. 5 хронологияның орнына сәйкестендіру әлі енгізілмеген. Контекстік жауапты тексеру — кілт сөздер арқылы алдын ала бағалау, адамның немесе семантикалық AI-дың толық тарихи бағалауы емес. Сайтты оқушыларға ресми емтихан дайындығы ретінде берер алдында барлық сұрақты куратор редакциялап, түпнұсқамен салыстыруы қажет.
